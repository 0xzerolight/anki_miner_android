# Security policy

## Supported versions

Anki Miner for Android has not published a production release. Security fixes are made on the active development branch until a supported-release table is added here.

## Reporting a vulnerability

Please use [GitHub's private vulnerability reporting](https://github.com/0xzerolight/anki_miner_android/security/advisories/new). Do not include a vulnerability, exploit, private media, subtitle content, Anki collection data, access token, signing material, or device identifier in a public issue.

Include the affected commit or version, Android version and ABI, reproduction conditions, impact, and the minimum diagnostic material needed to understand the report. Redact user content and secrets. The maintainer will assess reports on a best-effort basis; no response or remediation deadline is promised before the first supported release.

General bugs which do not expose security or private data may use the [public issue tracker](https://github.com/0xzerolight/anki_miner_android/issues).
